# BareMedix Prototype

**Live Demo:** https://akash-otter.github.io/baremedix-prototype/

A functional client-side HealthTech web prototype demonstrating core business logic and user flows.

## Technical Implementation
* **Frontend:** Vanilla HTML5, CSS3 (CSS variables for theming), and JavaScript.
* **Security:** Native browser `crypto.subtle` API for AES-256-GCM envelope encryption of medical records.
* **Media:** WebRTC `RTCPeerConnection` and `getUserMedia` API for the simulated video consultation module.
* **Compliance Flows:** ABHA ID integration and ABDM Federated Consent Manager simulated logic.
